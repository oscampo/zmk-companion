# ZMK Companion v1.0.0

First tagged release. ZMK Companion streams live data, custom text, and full
page layouts to a ZMK keyboard's onboard display over BLE, from a Windows
tray app and a small companion CLI.

## Highlights

- **Canvas editor**. design what shows on your keyboard's display: pages
  made of rows, each with its own tier (cell size), alignment, and font
  variant (Mono/Regular/Propo, per row).
- **Live data tokens**. clock, weather (up to 4 cities, with automatic
  day/night icons), foreign time zones, sports scores (NFL, NBA, NHL, and a
  long list of soccer leagues), battery, and BLE connection status.
- **Pomodoro timer**. configurable durations and cycle count, with a
  pickable icon per phase (work/break/long break).
- **Custom tokens**. `{custom.NAME}` values pushed live from your own
  scripts via `zkc --set`.
- **CLI (`zkc.exe`)**. send one-off text, stream stdin live (`--watch`),
  or set named tokens, from any script or shell pipeline.
- **Glyph picker**. browse and search the full embedded Nerd Font icon set
  by name or hex codepoint.
- **First-run welcome screen**. a short in-app tour, reachable any time
  from the tray's Help menu.
- **English / Español**. switch the whole UI's language from the tray menu.

## Requirements

- Windows 10, build 19041 or later
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- A ZMK keyboard with the display GATT service enabled, see
  [`docs/user_guide.md`](https://github.com/oscampo/zmk-companion/blob/main/docs/user_guide.md#firmware)
  for what that requires. Not supported on stock ZMK firmware.

## Install

Download `ZmkCompanion-Setup-1.0.0.exe` below and run it, no admin rights
needed. Full walkthrough in
[`docs/user_guide.md`](https://github.com/oscampo/zmk-companion/blob/main/docs/user_guide.md).

## Known limitations

- The display firmware is currently written for one reference keyboard
  (eyelash_corne). It should work on any ZMK board using a `nice_view`
  display, but that hasn't been verified on hardware other than the
  reference board yet, see
  [zmk-companion-template](https://github.com/oscampo/zmk-companion-template)
  if you'd like to try it and report back.
- `clients/cli` and `clients/ios` (older Python scripts) only speak the
  legacy plain-text display characteristic, not this app's current
  cell-grid/bitmap protocol.
